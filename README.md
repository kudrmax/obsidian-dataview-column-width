# Dataview Column Width

Drag the border between two headers of a Dataview table to change the width of those two columns, like in Bases.

- Works in Live Preview and Reading view, on desktop and mobile.
- Widths are remembered per note and stored as percentages of the note width, so the same layout fits any screen. The same query pasted into another note starts with automatic widths.
- A column can be made as narrow as about one letter (16 px) but never narrower, so it can always be dragged back.
- The right border of the last column narrows the whole table; the table never grows past the note width.
- Double-click a border to return the table to automatic widths.
- Renaming a note keeps its widths; deleting a note forgets them.

Columns are matched by their header text: if two Dataview tables in one note share a column name, they share its width.

Needs the Dataview plugin.
